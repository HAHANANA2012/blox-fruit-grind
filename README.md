# Blox Fruit Grind

Grinding service for Blox Fruits. Prices below are in USD and are starting prices.

## Leveling

| Service | Price |
| --- | ---: |
| Every 100 levels | $0.50 |
| 500 levels | $2.50 |
| 1,000 levels | $5.00 |

Formula: `levels / 100 x $0.50`, rounded up to the nearest 100 levels.

Leveling fees are separate from item fees. A level package includes normal experience
grinding only; it does not include puzzles, trials, mastery targets, boss drops, or
materials unless agreed in the order.

## Pricing Notes

- Prices assume the account already meets the required sea and level unless the leveling
	fee is added.
- A difficult request should be quoted before starting. Examples include multiple V4
	races, several rare drops, missing fighting styles, or missing crafting materials.
- A failed boss attempt caused by the service provider is not charged again. A retry is
	chargeable when the account disconnects, the customer changes the request, or the
	game changes the requirements.
- Confirm the exact scope and price in writing before beginning.
